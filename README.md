# 🏦 Bank Program (Java Console Application)

A secure, interactive command-line banking application built in **Java**. Manage your bank account, check balances, make deposits and withdrawals, and handle basic banking transactions right from your terminal.

---

## 🚀 Features

* **Account Management:** Check your current account balance at any time.
* **Deposits:** Securely add funds to your account with input validation.
* **Withdrawals:** Withdraw money with checks to prevent overdrafts or negative balances.
* **Interactive Menu:** Clean loop-based interface allowing multiple transactions in a single session.

---

## 🛠️ Technologies Used

* **Language:** Java (JDK 17 or higher)
* **Interface:** Command-Line Interface (CLI) / Standard Console I/O (`Scanner`)
